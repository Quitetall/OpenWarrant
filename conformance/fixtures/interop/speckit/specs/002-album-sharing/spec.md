# Feature Specification: Album Sharing

**Feature Branch**: `002-album-sharing`

**Created**: 2026-09-20

**Status**: Draft

**Input**: User description: "Share an album with a link"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Share by link (Priority: P1)

A user copies a link that opens the album for anyone who has it.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST create a link that opens the album read-only.
