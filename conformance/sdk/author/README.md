# SDK author/edit fixtures

Run `cargo run -p openwarrant-core --example sdk_probe -- --scope 76 --fixtures conformance/sdk`.
The driver first reuses the 22 document cases, then evaluates these file-backed
requests against literal expected bytes or named refusal codes. Expectations are
not generated by the implementation. Request metadata is an ordered list of
key/value pairs so duplicate fields remain observable. Unit text is exact UTF-8.

T54 covers minimum typed authoring; T55 covers literal shell text, duplicate
fields and structural injection; T56 covers explicit revision/body edits and
refused edits. FOOTER-08 covers synchronized titles, CRLF and details wrappers.
The public API tests additionally cover cancellation (discard returned bytes),
no-op identity, unchanged metadata/unit spans, legacy RC.2 edits, limits, optional
extensions and fenced markers. These are pure operations: no save, process,
signature, model, database or context compilation occurs.
