# RC.3 decision and supersession map

Reference map for the owner's revised direction. Earlier Q1–Q53 and C01–C15
history remains in [RC.2's map](../1.0.0-rc.2/decision-map.md); it is not rewritten.
These decisions override conflicting prospective RC.2 product requirements only
through adoption of this source set. They do not reinterpret old signed contracts.

| Owner decision | Replaces / refines | Binding destination |

Preserved decisions: bounded reviewable outcomes, exact immutable source/history,
protected expectations for qualification, independent verifier, truthful UNKNOWN,
no policy self-escalation, prompt-only unverified execution without fabricated human acts,
worktree writer serialization, affected-work hotline pausing, configurable retries
and spend limits, optional stronger profiles, Linux/macOS SDK, exact portable
context and conservative unknown applicability in conforming external compilers.

No LAMU database migration is selected by this amendment. Institutional ownership
and native source/actor authority remain at their owners. Secure signing transport
support must be qualified before advertising it; no new deployed SSH behavior is
claimed. The mark's public name and extra specialized profiles remain product
choices, not implicit legal or security certifications.
