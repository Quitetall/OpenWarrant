# Questions on FORMAT-1.0 draft 3: resolved

The 47 questions that writing the conformance corpus and its independent
Python implementation raised against `1.0.0-draft.3` are answered in the
text of draft 3, revision 1 (`docs/format/FORMAT-1.0.md`). The corpus
(`conformance/format/`), the Python modules and the schemas follow that
revision.

The questions themselves are in this file's git history. Where the corpus
still makes a choice the text leaves open, `reader.py`, `context.py` and
`tracker.py` mark it `READING:` and `conformance/format/README.md` lists it.
