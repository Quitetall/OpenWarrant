# Intent

Let users ask a configured local or cloud agent harness to draft a human-first
Warrant, inspect/edit the result, and save through the existing SDK. Remove manual
copying between a model response and the reference workbench without granting
execution or qualification authority.

No built-in provider credentials, model routing, semantic context compiler, human
signature, automatic execution or real-provider qualification claim is included.
Actual local/cloud observations remain required for Phase 3 qualification.
