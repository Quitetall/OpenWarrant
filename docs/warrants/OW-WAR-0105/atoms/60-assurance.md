# Assurance

## Acceptance Obligations

### OBL-001 — model-neutral draft survives validation
- **scope:** configured synthetic process, real SDK and reference HTTP/storage.
- **evidence:** prompt plus exact context produces validated editable source; save
  preserves intended fields and revision history. Local/cloud routing belongs to
  adapter; synthetic results do not qualify real providers.

### OBL-002 — invalid or unavailable work cannot become a draft
- **scope:** process, context, cost and API boundaries.
- **evidence:** malformed/extra authority fields, stale context digest, unknown cost
  with cap, timeout, oversized output and unavailable harness refuse visibly;
  interrupted attempt remains unknown and no duplicate dispatch is inferred.

### OBL-003 — UI and history preserve work boundaries
- **scope:** browser preview/save, immutable attempt records, current execution suite.
- **evidence:** no automatic save, signing or execution; browser preview does not
  overwrite unsaved work; records survive restart; authentication and replay rules
  exercised; package suite and repository integration checks pass.
