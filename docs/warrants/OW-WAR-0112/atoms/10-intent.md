# Intent

Project each program's corpus objectives from its configured SAS. LAMU's section
98 is a phase table; current parsing ignores it and substitutes OpenWarrant's
framework phases. A program with fewer than eleven phases has the same defect.

Support declared phase tables and preserve heading-based documents. Missing or
unsupported declarations must remain unknown, not become another program's exits.
No signature, acceptance, resolution, or recorded qualification changes.
