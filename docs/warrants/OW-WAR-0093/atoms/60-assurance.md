# Assurance

## Acceptance Obligations
### OBL-001 — Draft authoring persists exact source and revisions
- **scope:** local reference API and browser operations exercised by HTTP/QA fixtures.
- **evidence:** create, SDK-valid source, revision history, restart and unchanged old bytes.
### OBL-002 — Unauthorized and stale writes refuse
- **scope:** named HTTP and persistence boundary fixtures, not a production security claim.
- **evidence:** missing/wrong token, foreign Host/Origin, unsupported fields, malformed
  and over-limit requests, stale edit, competing store process and corrupt input refusal.
### OBL-003 — Existing records are reconciled without invented authority
- **scope:** every current legacy Warrant inventoried at the named source revision.
- **evidence:** recorded implementation and legacy states stay distinct; pending routes
  name actual missing work or human closure, with original records unchanged.
### OBL-004 — Independent review and structure
- **scope:** exact implementation diff and its bounded evidence.
- **evidence:** separate review contexts and repository gate; no self-issued Verified mark.
