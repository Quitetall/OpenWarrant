# Intent

Prevent damaged question storage from appearing as an empty successful hotline
read. Valid missing stores remain empty; damaged stores remain visible. Preserve
readable questions with diagnostics and refuse incomplete answer/queue context.
This repairs existing readers; it does not implement runtime pause/resume.
