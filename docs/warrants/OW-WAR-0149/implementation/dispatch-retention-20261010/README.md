# Retain emitted Dispatch packets before compile events

Unverified OW-WAR-0149 implementation, with OW-WAR-0111 native preservation observations. The public CLI previously recorded `dispatch.compiled` while only emitting the packet to the caller-selected path. A fresh native capture then reported `runtime.capture-source-unavailable`; moving the emitted bytes manually repaired capture but left a genuine historical audit gap. The earlier archive preserves that gap, without rewriting its history.

`war admin dispatch` now retains its exact packet under the Warrant's `dispatches/` directory before recording the compile event, while preserving the existing emitted copy and wire/digest semantics. The existing descriptor-relative create-without-replacement store rejects linked directories. A storage failure adds no compile event and leaves earlier bytes and the external output untouched. This is trusted-workspace record retention, not multi-file atomicity, writer fencing, execution, authority or a sandbox.

The public capture regression failed before the change and passed after it without caller file surgery. The linked-store refusal passed and preserved the journal, old packet and foreign files. Full CLI tests and strict Clippy are pending for this candidate.
