# Direct verifier response ambiguity

The bundled model wrapper refused ambiguous answers, but direct CLI ingestion did not. An actual public CLI fixture with two identical rows for one obligation wrote active verdict files and journal entries. The regression failed on those writes. Fixture responses and actors are explicitly synthetic; no model or real verification record was used.

Ingestion now checks the whole response for repeated obligation ids before subject/packet processing, historical retention, active records or journal writes. It refuses `verify.duplicate-obligation`, including identical rows, and leaves the input evidence and existing history intact. Response formats and digest domains are unchanged. An ordinary retry of an unchanged valid response still follows the existing replay path; repeated rows inside one response are refused.

All 44 reviewed-subject CLI integration tests pass, including legacy/v2 responses, identical/conflicting duplicates, unchanged records/journal, and valid bound restoration. The registered conformance run passes its positive corpus and a four-case direct CLI plant (2 checks, zero failures). The preserved earlier binary fails the same registered plant because records change. CLI all-target Clippy and formatting pass.

The first test command named a non-existent standalone target; the corrected target is `all`. The first test harness assumed absent verdict files existed; it was corrected to capture presence as well as bytes. Initial plant runs had undeclared reporting helpers and then stale generated corpus progress in the disposable clone; those failed observations remain retained. Regenerating the clone's actual registered source through `war admin compile` produced the passing run. The initial broader CLI regression run passed all 475 library tests and 268 integrations, failed the source/projection consistency check, and ignored four provisioned cases. Its rerun again passed 475 library tests and 268 integrations but failed the same projection check because the new report was added during the run. Both incomplete aggregate results remain failures.
