# Assurance

## Acceptance Obligations

### OBL-001 — question lifecycle preserves exact basis and progress
- **scope:** configured synthetic harness, real HTTP, SDK and Git worktrees.
- **evidence:** ask, retain checkpoint, answer, resume and complete; restart preserves
  pending questions and real identities; stale source or answer basis refuses.

### OBL-002 — routing and admission do not manufacture authority
- **scope:** configured responder authentication and current execution admission.
- **evidence:** technical advice cannot answer governing question; unauthorized
  identity, missing responder, pending blocker, unknown writer, exhausted budget
  and repeated request refuse; independent Warrant still executes.

### OBL-003 — browser and reports distinguish waiting from completion
- **scope:** reference webapp and deterministic execution reports.
- **evidence:** browser shows question and eligible next action; no completion word
  while waiting; final checks produce ordinary unverified completion report; package
  tests and repository gate pass. Real-provider and deployment qualification remain
  separately identified.
