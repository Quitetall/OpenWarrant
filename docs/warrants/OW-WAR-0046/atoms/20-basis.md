# Basis

## Governing Sources

§38, §39, §40, §43, §44, §45, §46, §56, §57, §91.10 tests 64–75, §91.11 tests 76–81, §91.12 tests 82–90.

## Prerequisites

OW-WAR-0016 through OW-WAR-0022 resolved. OW-WAR-0045 resolved, since a resolution needs an executed attempt.

## Assumptions and Unknowns

- **Evidenced premise.** §56.1's thirteen requirements are implemented as
  thirteen named booleans, each tested to block on its own.
- **Blocking unknown.** Independence. §46.3 requires blind process or agent
  review at `controlled`, and `Independence::none` — this repository's actual
  state — satisfies nothing, including `basic`.
  *Resolution requirement:* a verifier that did not author the work, with the
  independence dimensions recorded as achieved rather than asserted.
- **Accepted residual risk.** A gate can be askable, complete, return pass, and
  measure the wrong thing. §39's adequacy review is the only control that asks,
  and it is human.
  *Consequence if false:* a delivery closes on proof that is bounded, provenance-
  preserving, and about the wrong property.

## Constraints and Invariants

- **§44.5's conjunction is the only required pass.** One triple of
  thirty-six.
- **A performer's claim is not evidence** (§51.3), and §40.7's six substitutions
  stay forbidden under the pressure of wanting to close.
- **A required unknown blocks** (RQ-054). It is not a failure and it is not a
  pass, and it must not be resolved by reclassifying it.
