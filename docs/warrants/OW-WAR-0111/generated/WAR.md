# Intent

Replace the false export round-trip claim with a content-bearing preservation path.
A user can export retained Warrant records, move the archive away from its source,
import into an empty compatible destination, and re-export identical canonical
bytes while preserving historical states and evidence identities.

This follows OW30's unfulfilled preservation outcome without rewriting its signed
history. Out of scope: granting imported execution authority, inventing missing
history or evidence, deleting source records, or redefining old export digests.

# Basis

OW30, SAS §68.1–68.3 and RQ-082/083/084 govern preservation. Existing CLI merely
assembles metadata twice and trusts a reconnect boolean. Reproduction and source
analysis are retained in OW30/implementation/preservation-gap.md.

Core journal.rs is resolved-pinned by OW31 D-001. Preserve it unless a proper
correction authorizes change. Existing envelope/digest meanings are frozen.
Prepare an explicit versioned-format decision before promotion as a stable wire
contract; experimental implementation and tests remain unverified. No authority
or acceptance is implied by this Warrant or an imported record.

Shared KF stage must use the same archive definition and source identities.
Empty compatible KF instance and retained referenced evidence are prerequisites
for claiming SAS §68.3 interoperability; filesystem self-consistency alone is not.

   with strict version/path/duplicate/digest/size validation. Unknown optional
