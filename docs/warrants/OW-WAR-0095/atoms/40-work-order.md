# Work Order

## Preparation
Freeze build commit, installation inputs, host OS, scenario and required outcome before each
session. Assign pseudonymous IDs P1,P2,P3; store consent details privately under operator control.
Explain purpose, observed actions, voluntary participation, ability to stop, data retention and
who can access results. Collect only necessary measurements and redacted problem descriptions.
Do not place participant identity, credentials or private repository contents in public artifacts.

## Sessions
Each developer sets up one disposable repository, drafts a Warrant, starts bounded work and
inspects its actual completion, evidence and next steps. Use the real app and harness; a
facilitator takeover is recorded as assistance/failure, not silently counted as self-service.
Keep all attempts and interruptions; a retest links to its original result and new exact build.

Use a monotonic timer for active setup, routine administration, substantive review,
implementation and waiting. Count manual configuration/commands/metadata fixes as administration
or setup, not substantive review. Record total elapsed time too, with intervals that explain
category overlap or exclusion. Record observed start/end events and measurement method.

## Exit
All three participants complete their declared Warrant outcome. Each has at most600 seconds
active setup and at most60 seconds routine Warrant administration. Publish redacted observations,
threshold evaluation and every assistance/failure. Failure keeps study qualification open and
creates explicit repair/retest work. Unknown measurements stay unknown. Independent review
checks classifications and thresholds; human qualification remains a separate real act.

## Evidence
Add one session record per participant with consent confirmed (no identity), build/input digests,
OS, scenario, event intervals, categorized durations, assistance, outcome and failures. A template
is not evidence. Aggregate results cite those source records and retain exact denominator3.

## Autonomy
Preparation is authorized. Sessions require actual participant consent and runnable prerequisites.
No paid model calls without effective cost policy; use disposable data and preserve original history.
