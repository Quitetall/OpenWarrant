# Intent

establish this SDK/provider contract.

Package SDK, standard, CLI, adapted skills and their license notices. Document provider/workflow boundaries; verify Linux/macOS install and examples. Require Phase 3 workflow evidence before promotion; packaging rehearsal may proceed earlier.

## Scope

Phase 4 packaging; P2-INSTALL retained historical case. Owner: OpenWarrant release. Primary phase: 4.
Mixed-phase work delivers its standalone SDK subset before provider integration.

## Non-goals

No ownership of a second semantic compiler, no inferred permissions, no historical
signature rewriting. Phase 3 workflow delivery and Phase 4 promotion remain
separate from a Phase 1 library result. No work outside the stated outcome.
