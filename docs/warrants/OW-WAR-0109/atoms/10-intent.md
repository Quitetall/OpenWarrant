# Intent

An explicitly requested Warrant must remain visible while no eligible agent is
available, then start automatically when one becomes available. Today the reference
app supports immediate dispatch only. Build an opt-in durable queue through the
same admission evaluator and writer controls used for direct starts.

Out of scope: inventing human acceptance, paid metering, provider sandboxing,
automatic unknown-writer replacement, or changing legacy signed contracts.
