# Assurance

### OBL-001 — Exact bounded execution
- **scope:** HTTP start through synthetic sandbox-contract harness, real Git worktree and checks.
- **evidence:** Successful committed result; stale subject, duplicate writer and failed checks refuse completion.

### OBL-002 — Limits and uncertainty
- **scope:** Reference process controller and persisted attempts.
- **evidence:** Hard-cap unknown cost and verified-start refuse; timeout and restart never imply completion or permit uncertain writer replacement.

### OBL-003 — Skill and roadmap alignment
- **scope:** Local/cloud drafting guidance and remaining build plan.
- **evidence:** Commands match actual SDK/drafting seams, no credentials or paid calls; remaining work stays explicit.
