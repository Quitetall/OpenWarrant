# Intent

## Problem
The reference app can draft documents but cannot dispatch work or retain execution results.

## Desired Outcome
An opt-in configured harness executes an exact local draft in an isolated Git worktree,
with bounded attempts, serialized writers, required checks and durable unverified results.
Record model-neutral local/cloud skill drafting in the roadmap.

## Scope
Local reference workflow package, HTTP start/status, browser controls, harness request/result
protocol and real process/Git/HTTP refusal tests. Retain all execution history.

## Non-goals
Verified-start execution, secure acceptance, semantic compilation, automated recovery of
unknown writers, unrestricted model calls, full Phase 3 qualification and release publication.
