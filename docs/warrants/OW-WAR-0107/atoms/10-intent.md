# Intent

Reference execution can finish implementation and route questions, but it cannot
run the configured independent verification/repair/rebuttal loop. Add that loop
without turning performer reports into independent evidence or human acceptance.

Outcome: a configured exact candidate can be independently reviewed in a separate
workspace/context, repaired within explicit limits, reviewed again, and escalated
when disagreement or uncertainty remains. Prototype completion stays available.

Out of scope: real-model quality benchmarks, human assurance signatures, publishing
Stable, deployment, unknown-writer fencing/replacement and global CLI convergence.
