# Generated TypeScript record declarations

OW110 adds structural declarations generated by `war schemas` from the same JSON
schemas produced from Rust record types. Build the CLI with `--features schema`.
`war schemas --check` compares both existing JSON outputs and TypeScript outputs.
Never edit generated declarations by hand.

Each `schemas/typescript/<record>.ts` exports `Document`. Consumers use a meaningful
import alias, for example `import type { Document as Dispatch } from ...`.
The separate manifest binds source pack bytes, each source schema digest and each
TypeScript artifact digest. It does not change the existing JSON schema-pack
identity, member list, transitive digest calculation or FormatBasis.

Supported source draft: JSON Schema 2020-12. Supported structural constructs are
local `$defs` references, primitive types and nullable type lists, scalar constants
and enums, unions, objects with required/optional properties, maps, homogeneous
arrays and fixed-length prefixItems tuples. Unknown keywords, external/unresolved
references, structured enum constants, mixed named fields with typed additional
properties and unsupported tuple forms refuse generation. Adding support requires
fixtures; never silently replace a known unsupported shape with `any`.

TypeScript is not runtime validation. Numeric ranges/integrality, formats, array
uniqueness, non-tuple array length constraints, oneOf exclusivity and exact excess
property constraints remain JSON Schema/runtime checks. Unconstrained schemas use
`unknown`. Imported values still require trusted parsing, schema validation and
application authority checks. A successful type build does not verify a Warrant.

`conformance/integration/typescript/records.ts` imports actual generated Dispatch
types and checks a valid record plus required-field, literal and scalar refusals.
Run it and all generated `.ts` files with the pinned consumer TypeScript compiler,
strict mode and no emit. These fixtures are producer-side evidence only; actual
Knowledge Fabric package imports/build and runtime regression tests remain pending.
The shared contract is `docs/warrants/OW-WAR-0110/`.
