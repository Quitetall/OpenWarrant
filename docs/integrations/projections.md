# Shared projection contract

Revision 1 implementation draft; canonical owner OpenWarrant, shared work
OW-WAR-0080. LAMU implements projections with OpenWarrant SDK packet types.
No signature or assurance follows from context assembly.

The provider accepts a captured Snapshot and explicit F5 request. Task mode
requires an exact captured Warrant digest and one of the four F6 roles. Master
mode has task null, selects every parsed unit and opaque blob, and returns
not_evaluated readiness. Both modes preserve source metadata and captured basis.
No model call, live file reread or ambient policy occurs during compilation.

Task projections share outcome/scope/constraints and exact binding slices. Role
changes the fixed action and stop instructions, not authority or subject scope.
F7 human ENTRY and machine packet share membership and basis. Generated labels
are escaped as data; required source slices remain byte-exact, including CRLF.
Opaque content is linked to its blob, not interpreted. Brief lists reference
selected units instead of repeating required text. Missing lists say not supplied.
No performer assertion becomes a verification verdict. Until record evaluation
is integrated, task readiness remains blocked with an explicit limitation.

Background summaries are optional pre-authored sources, not model calls made by
this compiler. A LAMU profile extension `lamu:background-summary` declares entries
with summary unit, source targets, derivation method and model_produced boolean.
The summary unit and parents must be background. Each parent resolves against the
captured sources; originals remain available. Trust/classification must match
all parents, inherited taints must remain, and summary authority is unestablished.
Incomparable labels refuse until an explicit policy-capable integration exists.
This profile does not invent a universal ordering of trust/classification labels.
A summary can never replace a required rule or suppress dependency closure.

Rendering is bounded before each append. Exact bytes and deterministic structured
outputs are tested across all roles, master mode, tainted summary provenance,
performer claims, and full source bytes behind displayed context. Complete package
construction/offline semantic verification belongs to OW-WAR-0081; cache reuse and
budget invalidation belong to OW-WAR-0082. No partial package is published here.
