# Stops, failures and changes

The owner approved the two-class stop model and requested consolidation into SAS.
The authoritative candidate text is now [work-stop contract](../sas/drafts/1.0.0-rc.3/work-stop-contract.md),
a normative companion to SAS RC.3 §20. It contains scope definitions, work and
harness change handling, the scenario matrix, reporting and recovery requirements.

Work stops record declared completion. Agent stops record interruption. Tool
boundaries admit harness updates. Completion responses are defined by SAS §14.1;
context removal and evidence history are defined by its [context companion](../sas/drafts/1.0.0-rc.3/context-views-and-shared-work.md).
These are consolidated requirements, not claims that the current runtime enforces
them. This file is a navigation pointer, not a second copy of the rules.
