# Work Order

## Deliverables

1. A recorded baseline for every §94 measure that can be measured
   today, and an explicit `not_measurable_yet` for each that cannot, with the
   reason.
2. §94's eight derived metrics computed from real events.
3. §95 run against this repository's actual commit history, producing real
   untracked-work candidates.
4. A written statement of which §100 metrics remain unclaimable, and why.

## Frozen Surfaces

§94's measure names and §94's derived-metric names, which are transcribed from the SAS.

## Premade Instructions

- A measure that cannot be taken is recorded as not taken. It is
  never recorded as zero — zero is a measurement and "we did not look" is not.
- §95 candidates are reported, never auto-attributed. The detector refuses a
  relation with no reviewer, and that refusal is the point.
- Do not state any §100 reduction. There is one sample.

## Autonomy and Escalation

Tier T1 — measurement decides completion.

## Rollback
