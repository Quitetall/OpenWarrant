# Intent

Run the conformance battery as a service stage of a Warrant, so that a run —
not a code change, not a document — is a kind of work OpenWarrant can
dispatch, bound in time, receipt, and hand to a human as a submission that
asks only to be verified or to be unblocked.

## Out of scope

Scheduling, retries, and containment (cgroups, sandboxes): a run is bounded
in wall time and nothing else in 1.0.

# Basis

## Governing text

- SAS §47 (Dispatch), §51 (Stage Submission; §51.2 a performer may not
  request its own completion), §44.6 (runtime receipts).
- `docs/gates/ops.echo@1.0.0.yaml` and `docs/gates/ops.conformance.plants@1.0.0.yaml`.

## Prerequisites

- A built binary and the battery: `cargo build --workspace`.

## Assumptions

- The receipt's subject is the dispatch digest: the run is evidence about
  what was dispatched, not about the contract as a whole.

before anything is written; `war submit` refuses the same way for an
external submission, and one naming a dispatch this Warrant never compiled.
