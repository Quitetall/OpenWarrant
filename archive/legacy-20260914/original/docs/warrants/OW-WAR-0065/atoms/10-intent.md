# Intent

Decide, with numbers from this repository, which approximation of token
count OpenWarrant uses for §33.7 budgets and the projections that report an
estimate — and record the decision where a later reader finds it.

## Out of scope

Calling a tokenizer. No model API is part of this tool, and none will be
called to measure a Dispatch; the question is which local approximation to
name in the method id.
