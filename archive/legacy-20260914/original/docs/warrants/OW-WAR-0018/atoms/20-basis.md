# Basis

## Governing Sources

SAS §39: adversarial question, outcomes, executed attacks, required level, honest limitation.

## Prerequisites

OW-WAR-0016 and OW-WAR-0017 resolved.

## Assumptions and Unknowns

- **Evidenced premise.** This repository has three adequacy reviews written to
  §39's shape already, so the schema has a corpus.
- **Accepted residual risk.** An adequacy review is only as good as the attacker.
  Structure cannot supply adversarial imagination.

## Constraints and Invariants

- **The substring check is DELETED, not augmented.** Leaving it as a fallback
  means it keeps passing things.
- **A review with no executed attacks is incomplete** (§39.3). A list of questions
  with no answers is a plan, not a review — as this repository's own reviews
  currently say of themselves.
- **Honest limitation is required** (§39.5).
