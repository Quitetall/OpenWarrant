# Experimental native acceptance pack

Generated by `war admin schemas` (feature `schema`); do not edit.

These schemas describe canonical producer shapes for six draft formats. They
do not adopt a format, change the active v1 pack or bind a contract. TypeScript
provides structural types only; retain JSON Schema runtime validation.

The portable examples are unsigned illustrations, not project records, human
decisions, signatures or qualification. JSON Schema success proves no authority.
Original TOML bytes are retained exactly in the example record and proposal.
Sign the original TOML; do not reconstruct signature input from JSON. Enable
date-time format assertions in your JSON Schema validator.

Actual readers still enforce byte budgets, native version support, exact signed
field bindings, trusted keys, permissions, presence and fresh evidence. Canonical
UUIDs use lowercase hyphenated v7 form; permissive parsing is not authorization.

`pack.json` hashes every schema, type, example and this guide. The transitive
digest uses sorted relative-path:sha256 lines. TypeScript's manifest pins its
source schemas without a circular dependency on the containing pack.

Validate offline with `python3 conformance/native_schema_pack.py schemas/native-draft`
(jsonschema 4.26.0). `war admin schemas --check` refuses missing or changed artifacts.
